## Overview
Cluverse is a comprehensive platform for club management, featuring multiple modules including:
- **Elections**: Manage club elections and voting.
- **Events**: Organize and track club events.
- **Competencies**: AI-powered skill tracking and speech analysis.
- **Finance**: Budget management and payment tracking.
- **Sponsors**: Sponsorship management and tracking.

## Technology Stack
- **Framework**: Angular
- **Styling**: SCSS (with Dark/Light mode support)
- **State Management**: RxJS
- **Charts**: Chart.js

## Development
Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`.
